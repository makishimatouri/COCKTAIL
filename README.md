# Cocktail Craft

A comprehensive cocktail recipe and development skill for AI agents, covering IBA official recipes, competition-winning formulas, world-famous bar signatures, advanced techniques, and ingredient crafting.

## What's Inside

| File | Content |
|------|---------|
| `references/iba-cocktails-web.csv` | IBA 102 official recipes with precise measurements |
| `references/iba-cocktails.json` | IBA 89 cocktails (full Wiki edition) |
| `references/web-cocktail-db.md` | 80+ curated recipes from Difford's Guide, Liquor.com, PUNCH, Imbibe, Food & Wine |
| `references/brand-recipes.md` | Official recipes from Campari, Aperol, Chartreuse, Bacardi, Tanqueray + more brands |
| `references/famous-bar-signatures.md` | 15 world-class bar signatures (Death & Co, PDT, Connaught, Sips, Handshake, etc.) |
| `references/competition-recipes.md` | Diageo World Class + Bacardi Legacy winning recipes |
| `references/cocktail-classics.md` | Origin stories of 30+ classic cocktails |
| `references/recipe-design.md` | Methodology: 6 root recipes, flavor balance, development workflow |
| `references/techniques.md` | Advanced techniques: milk washing, sous vide, clarification, fat washing |
| `references/homemade-ingredients.md` | DIY bitters, tinctures, shrubs, cordials, oleo saccharum, vermouth |
| `references/glassware-garnish-ice.md` | Glassware guide, garnish techniques, ice types |
| `references/online-sources.md` | Search strategy for 5 major cocktail websites |
| `references/top-bars.md` | World's 50 Best Bars overview |

## Usage

This skill is compatible with any AI agent that supports the SKILL.md format (OpenClaw, Claude Code, Cursor, Codex CLI, etc.).

Place the `cocktail-craft/` directory in your agent's skills folder. The skill automatically triggers when users ask about cocktails, recipes, techniques, or bar culture.
